# App icon

Approved concept N01: Anton “CL” lettering in pale yellow `#fff29c`,
nav green `#60b048`, and a dark-green `#407c35` left edge.

`app-icon.svg` is the full-bleed master with outlined lettering. The iOS
asset is an opaque 1024 × 1024 PNG; the operating system supplies its mask.
The Android app uses the same outlines in adaptive and monochrome resources.
Do not bake rounded corners or a circular mask into the master.
